Sinyal ML — BTC / ETH / XAUUSD
MACHINE LEARNING
Tahap backtest
Ringkasan

Model machine learning yang menghasilkan sinyal beli / tahan / jual untuk BTC, ETH, dan XAUUSD setiap 15 menit.

Proses

Dilengkapi sistem manajemen risiko bernama "100 Green Forest" untuk menjaga keamanan posisi trading. Proyek ini masih dalam tahap backtest — sinyal buy yang pernah diuji langsung berhasil mencapai take profit, meski akurasi keseluruhan model saat ini masih di kisaran 50/50 dan belum layak dipakai untuk keputusan finansial nyata.

Ringkasan

Sistem otomasi berbasis model bahasa lokal untuk menjalankan tugas-tugas proyek tanpa bergantung pada API pihak ketiga.

Proses
